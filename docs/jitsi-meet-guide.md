# Инструкция по Jitsi Meet

[Jitsi Meet](https://ru.wikipedia.org/wiki/Jitsi) — бесплатное приложение с открытым исходным кодом для видеоконференций прямо в браузере.

[[TOC]]

## Серверы

Чтобы начать работу, выберите готовый сервер или установите Джитси на свой. Серверы отличаются версией приложения и тем, нужна ли для входа регистрация.

На официальном сервере [meet.jit.si](https://meet.jit.si/) создатель комнаты (модератор) должен войти через аккаунт Google или GitHub. Чтобы зарегистрироваться в GitHub, достаточно электронной почты — телефон не нужен.

Альтернативные серверы, где можно войти без регистрации:
* [meet.vas3k.cloud](https://meet.vas3k.cloud/)
* [allo.bim.land](https://allo.bim.land/)

## Модератор

Модератор — это первый участник, который зашёл в комнату. В списке пользователей он отмечен меткой «Moderator».

![Список пользователей в комнате Джитси.](/images/jitsi-meet-guide/jitsi-meet-guide-01.png)

Модератор может отключить микрофон любому участнику.

![](/images/jitsi-meet-guide/jitsi-meet-guide-02.png)

Модератор может удалить любого участника из комнаты.

![](/images/jitsi-meet-guide/jitsi-meet-guide-03.png)

Модератор может наделить правами любого участника. Эти права действуют, пока участник не выйдет из комнаты.

![](/images/jitsi-meet-guide/jitsi-meet-guide-04.png)
![](/images/jitsi-meet-guide/jitsi-meet-guide-05.png)

Если модератор выходит из комнаты, его права автоматически получает один из оставшихся участников.

## Лобби

Модератор может включить лобби. В этом случае новые участники смогут заходить в комнату только с его одобрения. Лобби включается в меню «Security options».

![](/images/jitsi-meet-guide/jitsi-meet-guide-06.png)
![](/images/jitsi-meet-guide/jitsi-meet-guide-07.png)

Когда кто-то пытается войти, модератор получает уведомление. С этим человеком можно начать личный чат.

![](/images/jitsi-meet-guide/jitsi-meet-guide-08.png)

Если задать пароль для лобби, те, кто его знает, смогут входить без одобрения модератора.

## Запись звонка

Кнопка записи звонка находится в главном меню. Она появляется только в браузере Chrome — в Firefox этой функции нет.

![](/images/jitsi-meet-guide/jitsi-meet-guide-09.png)

На серверах без регистрации доступна только локальная запись. Сохраняется всё, что происходит во вкладке, включая движения курсора. Если у пользователя, который ведёт запись, пропадёт связь, то, вероятно, запись остановится.
